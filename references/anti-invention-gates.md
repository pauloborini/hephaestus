# Anti-invention gates

Compact per-phase pipeline matrix. **Inventing** = emitting `DEC` / `path` / `folder` / `text` without the mandatory evidence from the middle column. Bans pulled from language already present in the prompts (never invent a `DEC` without a source; paths only on the closed list; the overlay never invents folders; do not rewrite solid INVs).

| Phase | May produce | Mandatory evidence | Inventing = |
|------|---------------|----------------------|------------|
| `preflight` | `mode` (`adopt`/`maintain`) + resolved catalog + checkpoint | `meta.adoptionStatus` and same-run receipts; git + proven baseline; base `catalog/*` ± `routing` overlay | **path/folder/text**: inventing mode by tree heuristic; inventing a folder via overlay; migrating an unknown state field (D4); cleaning/reverting a previous run's state on its own initiative (the handoff orients, the user decides) |
| `discover` | source / risk / missing inventory + defect findings (`findings.json`) + `issues-visibility` question (adopt, non-blocking) | `mode`-guided scan; `naming-policy` + `drift-catalog`; SCHEMA closed list §2/§4; `findingSignature` per finding (normalized type + path + statement); `questionKey` + `contextFingerprint` on the question | **path/folder**: inventorying an out-of-mode-scope path as canonical; treating the whole vault root as the closed list; deciding `issues/` visibility for the user (the question presents the trade-off, never decides) |
| `snapshot` | `snapshot.json` (frozen bytes) | `discover` inventory; byte-for-byte copy of listed sources | **text/path**: "fixing" or rewriting a source in the snapshot; including a non-inventoried path |
| `fragment` | `fragments.json` + `provenance[]` | units cut from the snapshot; `fragment.schema.json` schema | **text/path**: fragmenting without provenance; inventing a statement the source does not carry; **inventing `territory`/`regime`/destination in fragment** (that belongs to `route`) = fail |
| `route` | `routing.json` + `questions.json` queue | cascade (shield→1…5); match with evidence (`path`/`questionKey`/`pattern`); destination ∈ four territories / closed list | **path/folder**: destination outside the closed list; overlay inventing a folder; `.app-work/` with `generate`/`reconcile`; vault keep outside §2 |
| `reconcile` | `identity-map.json` (`action`/`decId`) | heading/source stating the rule; `max` inventory (live + `## History`); match by canonical ID or statement | **DEC/text**: inventing a rule the source does not state; reusing/renumbering `DEC-NNN`; minting directly from an `.app-work/` origin, without a confirmed and frozen human fragment (INV9); ID without inventory |
| `interview` | persistent answers in state or temporary ones in `run-answers.json`; additive human-promotion snapshot | question with `questionKey` + `contextFingerprint`; human answer; temporary one bound to `runId`; closed territories | **folder/path**: writing a new folder into `routing.overlay`; destination outside the closed list; promoting an unknown folder to catalog default |
| `plan` | `plan.json` / `plan.md` | ledgers (`routing`, identity-map, questions, findings); explicit destructiveness | **text**: destructive operation of any provenance without approval, evidence, and current `planFingerprint` (INV7); omitting a real removal/relocate/overwrite (versioned contract → `@AGENTS.md` bridge, including in maintain) |
| `compose` | `staging/**` + `staging-manifest.json` | plan + identity-map + templates; only closed-list §2 folders; `keep` = bytes; `issues/INDEX.md` upsert with dedupe by `findingSignature` | **folder/text**: creating a folder outside the list; empty file; rewriting the `shield` block; inventing a `DEC` beyond the map; copying a decision value into `project-rules/` (INV4) |
| `verify_staging` | staging verdict (+ finding in `findings.json` when a gate fails a defect) | schemas/manifests over staging; package contract | **text**: "passing" with a violation; inventing an artifact missing from the manifest |
| `apply` | package on worktree (single tx) + backup | approved staging-manifest (`issues/INDEX.md` upsert included, materialized by compose); complete backup; relocate→…→keep order | **path/DEC**: writing outside the manifest list; minting `ISSUE-NNN` ad-hoc outside staging; reusing `ISSUE-NNN`; mutating the installed skill |
| `verify_applied` | applied verdict / rollback (+ finding in `findings.json` when a gate fails a defect) | disk hash ≡ staging-manifest; recovery limited to own receipts | **text**: declaring valid with a divergent hash; reverting `hephaestus-state.json` (INV1 exception) |
| `closeout` | `report.md` + verdict | post-apply routing/coverage/identity-map; nominal LLM-residue list | **DEC/path/text**: altering territories in closeout; inventing a `DEC`/pending without a ledger; `ready` with incomplete adoption |

## Cross-cutting reminders (already in the prompts)

- **DEC without a source** — `reconcile`: "never invent a rule the source does not state"; minting only with evidence + `max+1`.
- **Path outside the closed list** — territories = `AGENTS.md` | `project-rules/` | SCHEMA §2 (`_app-vault/**`, `.app-work/**`); vault keep only `INDEX` / `docs/decisions` / `docs/TEMPLATES` / `specs`.
- **Folder via overlay** — `routing` block: the overlay never invents a folder; `includeInPack` never writes a new folder into the overlay.
- **Solid INVs** — do not rewrite normative INV1–INV11 / CN* prose beyond moving/extracting; keep-bytes when destination == origin.
