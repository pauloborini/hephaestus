# RULES: WIDGETS

## Widgets padrão
- Botões: `StandardButton`, `StandardTextButton`.
- Campos: `StandardFormField`, `CurrencyInputField`.
- Containers: `StandardCard`, `StandardActionCard`.
- Estrutura: `StandardAppbar`, `StandardBottomBar`.

## Regra de uso
- Não recriar widget nativo quando já houver padrão do projeto.

## Acessibilidade
- Garantir truncamento de textos longos.
- Respeitar contraste do design system.
- Usar estados `isLoading`/`isEnabled` dos widgets padrão.
